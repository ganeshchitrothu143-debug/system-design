# Issue Tracker · First FDE project

A club needs a shared place to record and resolve problems. Work through one user journey from a customer conversation to a hosted demonstration. Start with [requirements](01-requirements.md) and [system design](01a-system-design.md). Then work through [frontend](02-frontend.md), [database](03-database.md), [backend](04-backend.md), [integration and testing](05-integration-testing.md), and [deployment](06-deployment.md). Use [AI setup](07-ai-setup.md) whenever you reach your first AI task. Finish with the [one-page review](08-build-with-ai.md).

Work in 40-minute sessions. Spend 5 minutes recalling, 10 designing, 15 building, 5 verifying and 5 explaining. Record one design decision, one AI instruction and one observed result per session. Your final demo creates and resolves an issue, then shows that it survived an app reload. Use invented data for the hosted demo.
